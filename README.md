# Oyedoh David - Portfolio Website

A modern, high-quality portfolio website for Oyedoh David - Cybersecurity Engineer & Web Developer, featuring a glassmorphism design with a tech/cybersecurity aesthetic.

## 🎨 Features

- **Glassmorphism UI**: Clean glass transparency effects with backdrop blur
- **Dark Theme**: Cybersecurity-inspired dark color scheme with cyan/blue accents
- **Responsive Design**: Fully responsive across all devices
- **Smooth Animations**: Subtle hover effects and transitions
- **Modern Stack**: Built with TypeScript, React, and Tailwind CSS

## 🛠️ Tech Stack

- **Framework**: React 18 with TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Deployment**: Optimized for Vercel

## 📂 Project Structure

```
src/
├── components/
│   ├── Navigation.tsx    # Fixed navigation with active states
│   ├── Hero.tsx          # Hero section with main intro
│   ├── Skills.tsx        # Technical skills showcase
│   ├── Projects.tsx      # Web development portfolio
│   ├── Cybersecurity.tsx # Security expertise section
│   └── Contact.tsx       # Contact form and information
├── App.tsx               # Main app component
├── main.tsx             # Entry point
└── index.css            # Global styles and animations
```

## 🚀 Sections

1. **Home/Hero**: Introduction with animated background and call-to-action
2. **Skills**: Three categories - Web Development, Cybersecurity, and Tools & Platforms
3. **Projects**: Featured web development work including:
   - Sales Suite Platform
   - Task Manager Pro
   - E-Commerce Platform
   - Weather Dashboard
   - Portfolio Showcase
   - API Gateway Service
4. **Cybersecurity**: Security services, tools, and certifications
5. **Contact**: Contact form and availability information
